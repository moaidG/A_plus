## 1. دوال الملفات (File I/O)

### readFile / اقرأملف
قراءة محتوى ملف نصي كامل.

```
readFile("path")
اقرأملف("المسار")
```
- **المُدخل**: مسار الملف (نص)
- **المخرج**: محتوى الملف (نص)
- **مثال**:
```
let data = readFile("file.txt")
let data2 = اقرأملف("file.txt")
```

### writeFile / اكتبملف
كتابة محتوى إلى ملف (ينشئه إن لم يكن موجوداً).

```
writeFile("path", "content")
اكتبملف("المسار", "المحتوى")
```
- **المُدخل**: مسار الملف + المحتوى
- **المخرج**: 1 عند النجاح
- **مثال**:
```
writeFile("out.txt", "Hello World")
اكتبملف("out.txt", "مرحباً")
```

### fileExists / ملفموجود
التحقق من وجود ملف.

```
fileExists("path")
ملفموجود("المسار")
```
- **المُدخل**: مسار الملف
- **المخرج**: 1 إذا موجود، 0 إذا غير موجود
- **مثال**:
```
if fileExists("data.dat") { print("موجود") }
if ملفموجود("data.dat") { print("موجود") }
```

### appendFile / أضفلملف
إضافة محتوى إلى نهاية ملف.

```
appendFile("path", "content")
أضفلملف("المسار", "المحتوى")
```
- **المُدخل**: مسار الملف + المحتوى
- **المخرج**: 1 عند النجاح
- **مثال**:
```
appendFile("log.txt", "سطر جديد\n")
أضفلملف("log.txt", "سطر جديد\n")
```

### deleteFile / احذفملف
حذف ملف.

```
deleteFile("path")
احذفملف("المسار")
```
- **المُدخل**: مسار الملف
- **المخرج**: 1 عند النجاح
- **مثال**:
```
deleteFile("temp.txt")
احذفملف("temp.txt")
```

## 2. دوال التوقيت (Timer)

### sleep / أنتظر
إيقاف التنفيذ لمدة معينة (بالملي ثانية).

```
sleep(milliseconds)
أنتظر(ملي_ثانية)
```
- **المُدخل**: عدد الملي ثانية (رقم)
- **المخرج**: 0
- **مثال**:
```
print("انتظر 3 ثواني...")
sleep(3000)
print("تم!")
```

### timestamp / الوقت
الحصول على الوقت الحالي (Unix timestamp) بالملي ثانية.

```
timestamp()
الوقت()
```
- **المُدخل**: لا شيء
- **المخرج**: رقم (ملي ثانية منذ 1970-01-01)
- **مثال**:
```
let start = timestamp()
sleep(1000)
let elapsed = timestamp() - start
print("استغرق " + elapsed + " ملي ثانية")
```

## 3. دوال وحدة التحكم (Console TUI)

### consoleClear / مسحشاشة
مسح شاشة وحدة التحكم.

```
consoleClear()
مسحشاشة()
```
- **المُدخل**: لا شيء
- **المخرج**: 0

### consoleSetCursor / حددموقعمؤشر
تحديد موقع المؤشر في وحدة التحكم (x = عمود، y = صف).

```
consoleSetCursor(x, y)
حددموقعمؤشر(س, ص)
```
- **المُدخل**: x (عمود)، y (صف)
- **المخرج**: 0
- **مثال**:
```
consoleClear()
consoleSetCursor(10, 5)
print("مرحباً")
```

### consoleColor / لوننص
تغيير لون النص في وحدة التحكم. الألوان المدعومة:
black, blue, cyan, darkblue, darkcyan, darkgray, darkgreen, darkmagenta, darkred, darkyellow, gray, green, magenta, red, white, yellow

```
consoleColor("colorName")
لوننص("اسم_اللون")
```
- **المُدخل**: اسم اللون (نص)
- **المخرج**: 0
- **مثال**:
```
consoleColor("red")
print("هذا النص أحمر")
consoleColor("green")
print("هذا النص أخضر")
لوننص("أزرق")
print("هذا النص أزرق")
```

## 4. دوال JSON والتعبيرات المنتظمة و HTTP

### jsonParse / تحليلJson
تحليل نص JSON إلى قيم A+ (أرقام، نصوص، مصفوفات، كائنات).

```
jsonParse("jsonString")
تحليلJson("نص_Json")
```
- **المُدخل**: نص JSON
- **المخرج**: قيمة A+ (رقم، نص، مصفوفة، قاموس)
- **مثال**:
```
let obj = jsonParse('{"name": "A+", "version": 1}')
print(obj["name"])      # A+
print(obj["version"])   # 1

let arr = jsonParse('[10, 20, 30]')
print(arr[1])           # 20
```

### regexMatch / تطابقRegex
اختبار إذا كان النص يطابق نمط تعبير منتظم. يستخدم `Regex.IsMatch`.

```
regexMatch("input", "pattern")
تطابقRegex("المدخل", "النمط")
```
- **المُدخل**: النص + نمط التعبير المنتظم
- **المخرج**: 1 (يطابق) أو 0 (لا يطابق)
- **مثال**:
```
if regexMatch("test@example.com", "^.+@.+\\..+$") {
    print("بريد إلكتروني صحيح")
}
```

### regexFind / بحثRegex
البحث عن أول تطابق لتعبير منتظم في نص. يستخدم `Regex.Match`.

```
regexFind("input", "pattern")
بحثRegex("المدخل", "النمط")
```
- **المُدخل**: النص + نمط التعبير المنتظم
- **المخرج**: مصفوفة تحتوي على التطابق الكامل أولاً، ثم المجموعات (groups)
- **مثال**:
```
let m = regexFind("hello 42 world", "(\\d+)")
print(m[0])   # "42"
print(m[1])   # "42" (capture group)
```

### regexReplace / استبدلRegex
استبدال جميع التطابقات لتعبير منتظم في نص.

```
regexReplace("input", "pattern", "replacement")
استبدلRegex("المدخل", "النمط", "الاستبدال")
```
- **المُدخل**: النص + النمط + نص الاستبدال
- **المخرج**: النص بعد الاستبدال
- **مثال**:
```
let result = regexReplace("abc123def456", "\\d+", "X")
print(result)   # "abcXdefX"
```

### httpGet / طلبHttpGet
تنفيذ طلب HTTP GET والحصول على الرد كنص.

```
httpGet("url")
طلبHttpGet("رابط")
```
- **المُدخل**: رابط URL
- **المخرج**: نص الرد
- **مثال**:
```
let response = httpGet("https://api.example.com/data")
print(response)
```

## 5. دوال المصفوفات (List LINQ)

### set / تعيين
تعيين قيمة في المصفوفة عند فهرس معين.

```
arr.set(index, value)
arr.تعيين(الفهرس, القيمة)
```
- **المُدخل**: index + value
- **المخرج**: القيمة التي تم تعيينها
- **مثال**:
```
let arr = [10, 20, 30]
arr.set(1, 99)   # arr = [10, 99, 30]
```

### push / أضف / add
إضافة عنصر إلى نهاية المصفوفة.

```
arr.push(value)
arr.أضف(القيمة)
arr.add(value)
```
- **المُدخل**: قيمة
- **المخرج**: القيمة المضافة
- **مثال**:
```
let arr = [1, 2, 3]
arr.push(4)   # arr = [1, 2, 3, 4]
arr.add(5)    # arr = [1, 2, 3, 4, 5]
```

### pop / احذف
إزالة وإرجاع آخر عنصر من المصفوفة.

```
arr.pop()
arr.احذف()
```
- **المُدخل**: لا شيء
- **المخرج**: العنصر المحذوف (آخر عنصر)
- **مثال**:
```
let arr = [1, 2, 3]
let last = arr.pop()   # last = 3, arr = [1, 2]
```

### get / احصل
الحصول على عنصر من المصفوفة بفهرس معين.

```
arr.get(index)
arr.احصل(الفهرس)
```
- **المُدخل**: index
- **المخرج**: العنصر في ذلك الفهرس
- **مثال**:
```
let arr = [10, 20, 30]
let val = arr.get(1)   # val = 20
```

### len / طول
الحصول على طول المصفوفة (عدد العناصر). يمكن استخدامه كخاصية أو كدالة.

```
arr.len()     # كدالة
arr.طول()     # كدالة بالعربي
arr.len       # كخاصية
arr.length    # كخاصية إنجليزية
arr.طول      # كخاصية عربية
```
- **المُدخل**: لا شيء
- **المخرج**: عدد العناصر (رقم)
- **مثال**:
```
let arr = [10, 20, 30]
print(arr.len)      # 3
print(arr.length)   # 3
```

### join / انضم
دمج عناصر المصفوفة في نص واحد مع فاصل اختياري.

```
arr.join("separator")
arr.انضم("الفاصل")
```
- **المُدخل**: نص فاصل (اختياري، افتراضي "")
- **المخرج**: النص المدمج
- **مثال**:
```
let arr = ["a", "b", "c"]
print(arr.join(", "))   # "a, b, c"
```

### forEach / لكل
تنفيذ دالة على كل عنصر في المصفوفة. العنصر الحالي يُخزن في متغير `it`.

```
arr.forEach("functionName")
arr.لكل("اسم_الدالة")
```
- **المُدخل**: اسم الدالة (نص)
- **المخرج**: 0
- **مثال**:
```
let arr = [1, 2, 3]
func show() { print(it) }
arr.forEach("show")   # 1 2 3
```

### map / حول
إنشاء مصفوفة جديدة بتطبيق دالة تحويل على كل عنصر. العنصر الحالي في `it`.

```
arr.map("functionName")
arr.حول("اسم_الدالة")
```
- **المُدخل**: اسم دالة التحويل
- **المخرج**: مصفوفة جديدة
- **مثال**:
```
let arr = [1, 2, 3]
func double() { return it * 2 }
let result = arr.map("double")   # [2, 4, 6]
```

### filter / صفي
تصفية المصفوفة وإرجاع عناصر تحقق شرطاً معيناً. العنصر الحالي في `it`.

```
arr.filter("predicateFunction")
arr.صفي("اسم_دالة_الشرط")
```
- **المُدخل**: اسم دالة الشرط (ترجع 1 للقبول، 0 للرفض)
- **المخرج**: مصفوفة جديدة (العناصر المقبولة)
- **مثال**:
```
let arr = [1, 2, 3, 4, 5]
func isEven() { return it % 2 == 0 }
let even = arr.filter("isEven")   # [2, 4]
```

### reduce / اختزل
اختزال المصفوفة إلى قيمة واحدة باستخدام دالة تراكمية.
المتغيرات المتاحة في الدالة: `acc` (المجمع)، `it` (العنصر الحالي)، `idx` (الفهرس).

```
arr.reduce("functionName", initialAcc)
arr.اختزل("اسم_الدالة", القيمة_الابتدائية)
```
- **المُدخل**: اسم الدالة + قيمة ابتدائية اختيارية (افتراضي 0)
- **المخرج**: القيمة النهائية بعد الاختزال
- **مثال**:
```
let arr = [1, 2, 3, 4]
func sum() { acc = acc + it }
let total = arr.reduce("sum", 0)    # 10
```

### sort / رتب
ترتيب عناصر المصفوفة تصاعدياً (نصياً). يعدّل المصفوفة الأصلية.

```
arr.sort()
arr.رتب()
```
- **المُدخل**: لا شيء
- **المخرج**: 0
- **مثال**:
```
let arr = [3, 1, 4, 1, 5]
arr.sort()   # arr = [1, 1, 3, 4, 5]
```

### reverse / عكس
عكس ترتيب عناصر المصفوفة. يعدّل المصفوفة الأصلية.

```
arr.reverse()
arr.عكس()
```
- **المُدخل**: لا شيء
- **المخرج**: 0
- **مثال**:
```
let arr = [1, 2, 3]
arr.reverse()   # arr = [3, 2, 1]
```

## 6. دوال النصوص (String Methods)

### len / طول
طول النص (عدد الأحرف).

```
str.len()
str.طول()
```
- **المُدخل**: لا شيء
- **المخرج**: رقم (عدد الأحرف)
- **مثال**:
```
let s = "مرحباً"
print(s.len())   # 6
```

### sub / اقتطع
استخراج جزء من النص بدءاً من فهرس معين، بطول اختياري.

```
str.sub(start, length)
str.اقتطع(البداية, الطول)
```
- **المُدخل**: start (فهرس البداية) + length (اختياري)
- **المخرج**: النص المقتطع
- **مثال**:
```
let s = "Hello World"
print(s.sub(0, 5))   # "Hello"
print(s.sub(6))      # "World"
```

### contains / يحتوي
التحقق مما إذا كان النص يحتوي على نص فرعي.

```
str.contains("substring")
str.يحتوي("نص_فرعي")
```
- **المُدخل**: النص الفرعي
- **المخرج**: 1 (يحتوي) أو 0 (لا يحتوي)
- **مثال**:
```
let s = "Hello World"
if s.contains("World") { print("نعم") }
```

### replace / استبدل
استبدال جميع occurrences لنص فرعي بنص آخر.

```
str.replace("old", "new")
str.استبدل("قديم", "جديد")
```
- **المُدخل**: old + new
- **المخرج**: النص بعد الاستبدال
- **مثال**:
```
let s = "Hello World"
print(s.replace("World", "A+"))   # "Hello A+"
```

### upper / كبير
تحويل النص إلى أحرف كبيرة (UPPERCASE).

```
str.upper()
str.كبير()
```
- **المُدخل**: لا شيء
- **المخرج**: النص بأحرف كبيرة
- **مثال**:
```
let s = "Hello"
print(s.upper())   # "HELLO"
```

### lower / صغير
تحويل النص إلى أحرف صغيرة (lowercase).

```
str.lower()
str.صغير()
```
- **المُدخل**: لا شيء
- **المخرج**: النص بأحرف صغيرة
- **مثال**:
```
let s = "Hello"
print(s.lower())   # "hello"
```

### trim / قص
إزالة المسافات البيضاء من بداية ونهاية النص.

```
str.trim()
str.قص()
```
- **المُدخل**: لا شيء
- **المخرج**: النص بعد القص
- **مثال**:
```
let s = "  Hello  "
print(s.trim())   # "Hello"
```

### indexOf / موقع
إرجاع الفهرس (0-based) لأول occurrence لنص فرعي، أو -1 إذا لم يوجد.

```
str.indexOf("substring")
str.موقع("نص_فرعي")
```
- **المُدخل**: النص الفرعي
- **المخرج**: رقم (الفهرس)
- **مثال**:
```
let s = "Hello World"
print(s.indexOf("World"))   # 6
print(s.indexOf("xyz"))     # -1
```

### split / قسم
تقسيم النص إلى مصفوفة باستخدام فاصل.

```
str.split("separator")
str.قسم("الفاصل")
```
- **المُدخل**: الفاصل (نص، يؤخذ أول حرف منه)
- **المخرج**: مصفوفة من النصوص
- **مثال**:
```
let s = "a,b,c"
let arr = s.split(",")   # ["a", "b", "c"]
```

### forEach / لكل
التكرار على كل حرف في النص. الحرف الحالي يُخزن في `it`.

```
str.forEach("functionName")
str.لكل("اسم_الدالة")
```
- **المُدخل**: اسم الدالة
- **المخرج**: 0
- **مثال**:
```
let s = "ABC"
func showChar() { print(it) }
s.forEach("showChar")   # A B C
```

### startsWith / يبدأ
التحقق مما إذا كان النص يبدأ ببادئة معينة.

```
str.startsWith("prefix")
str.يبدأ("بادئة")
```
- **المُدخل**: البادئة (نص)
- **المخرج**: 1 (نعم) أو 0 (لا)
- **مثال**:
```
let s = "Hello World"
if s.startsWith("Hello") { print("نعم") }
```

### endsWith / ينتهي
التحقق مما إذا كان النص ينتهي بلاحقة معينة.

```
str.endsWith("suffix")
str.ينتهي("لاحقة")
```
- **المُدخل**: اللاحقة (نص)
- **المخرج**: 1 (نعم) أو 0 (لا)
- **مثال**:
```
let s = "Hello World"
if s.endsWith("World") { print("نعم") }
```

### padLeft / املأيسار
تعبئة النص من اليسار بطول معين، باستخدام حرف تعبئة اختياري (افتراضي مسافة).

```
str.padLeft(totalWidth, padChar)
str.املأيسار(الطول_الإجمالي, حرف_التعبئة)
```
- **المُدخل**: totalWidth + padChar (اختياري، افتراضي " ")
- **المخرج**: النص بعد التعبئة
- **مثال**:
```
let s = "42"
print(s.padLeft(5, "0"))   # "00042"
print(s.padLeft(5))        # "   42"
```

### padRight / املأيمين
تعبئة النص من اليمين بطول معين، باستخدام حرف تعبئة اختياري.

```
str.padRight(totalWidth, padChar)
str.املأيمين(الطول_الإجمالي, حرف_التعبئة)
```
- **المُدخل**: totalWidth + padChar (اختياري)
- **المخرج**: النص بعد التعبئة
- **مثال**:
```
let s = "42"
print(s.padRight(5, "0"))   # "42000"
```

### repeat / كرر
تكرار النص عدداً معيناً من المرات.

```
str.repeat(count)
str.كرر(العدد)
```
- **المُدخل**: count (عدد التكرارات)
- **المخرج**: النص المكرر
- **مثال**:
```
let s = "Ha"
print(s.repeat(3))   # "HaHaHa"
```

### format / نسق
تنسيق النص باستخدام .NET `string.Format`. استخدم `{0}`, `{1}`, إلخ كعناصر نائبة.

```
str.format(arg0, arg1, ...)
str.نسق(الوسيط0, الوسيط1, ...)
```
- **المُدخل**: وسائط متعددة (حسب الحاجة)
- **المخرج**: النص بعد التنسيق
- **مثال**:
```
let name = "A+"
let ver = 1
print("Hello {0} version {1}".format(name, ver))
# "Hello A+ version 1"
```

## 7. دوال 3D

يتم إنشاء كائنات 3D باستخدام `new` مع أسماء خاصة:

### Camera / كاميرا
إنشاء كاميرا منظور ثلاثي الأبعاد.

```
new Camera(x, y, z)
جديد كاميرا(س, ص, ع)
```
- **المُدخل**: x, y, z (اختياري، افتراضي 0, 0, 5)
- **المخرج**: كائن كاميرا يمكن تعيينه لـ `viewport.cam`
- **مثال**:
```
let cam = new Camera(0, 0, 5)
vp.cam = cam
```

### Light / ضوء
إنشاء ضوء اتجاهي ثلاثي الأبعاد.

```
new Light(x, y, power)
جديد ضوء(س, ص, القوة)
```
- **المُدخل**: x, y, power (اختياري، افتراضي 0, 0, 1)
- **المخرج**: كائن ضوء يمكن تعيينه لـ `viewport.ligt`
- **مثال**:
```
let light = new Light(0, -1, 1)
vp.ligt = light
```

### Object / كائن
إنشاء مجسم ثلاثي الأبعاد.

```
new Object(x, y, path)
جديد كائن(س, ص, المسار)
```
- **المُدخل**: x, y, path (path > 0 ينشئ مكعباً، path <= 0 ينشئ مثلثاً)
- **المخرج**: كائن ثلاثي الأبعاد يمكن تعيينه لـ `viewport.objet`
- **مثال**:
```
let obj = new Object(0, 0, 1)   # مكعب
vp.objet = obj
```

## 8. دوال مساعدة (Utility)

### help / مساعدة
عرض معلومات مساعدة عن دالة أو خاصية.

```
help("name")
مساعدة("الاسم")
```
- **المُدخل**: اسم الدالة أو الخاصية
- **المخرج**: نص توضيحي
- **مثال**:
```
help("readFile")
مساعدة("readFile")
```

### typeof / نوع
معرفة نوع قيمة معينة.

```
typeof(value)
نوع(القيمة)
```
- **المُدخل**: أي قيمة
- **المخرج**: نص يصف النوع: "number", "string", "bool", "object", "array", "unknown"
- **مثال**:
```
print(typeof(42))        # "number"
print(typeof("Hello"))   # "string"
print(typeof(true))      # "bool"
print(typeof([1,2,3]))   # "array"
```

### platform / منصة
معرفة نظام التشغيل الحالي.

```
platform()
منصة()
```
- **المُدخل**: لا شيء
- **المخرج**: "windows", "linux", "macos", or "other"
- **مثال**:
```
if platform() == "windows" {
    print("أنت على ويندوز")
}
```

### dotnet / نت
استدعاء دالة .NET ثابتة مباشرة.

```
dotnet("TypeName", "MethodName", arg1, arg2, ...)
نت("اسم_النوع", "اسم_الدالة", وسيط1, وسيط2, ...)
```
- **المُدخل**: اسم النوع (كامل مع namespace) + اسم الدالة + وسائط الدالة
- **المخرج**: قيمة الإرجاع من دالة .NET
- **مثال**:
```
dotnet("System.Math", "Sqrt", 16)        # 4
dotnet("System.Console", "WriteLine", "Hello from .NET!")
```

### input / اقرأ
قراءة سطر نصي من المستخدم.

```
input("prompt")
اقرأ("النص_التوجيهي")
```
- **المُدخل**: نص توجيهي اختياري
- **المخرج**: النص الذي أدخله المستخدم
- **مثال**:
```
let name = input("ادخل اسمك: ")
print("مرحباً " + name)
```

### trace / تتبع
تسجيل رسالة تتبع (لأغراض التصحيح).

```
trace("message")
تتبع("الرسالة")
```
- **المُدخل**: رسالة نصية
- **المخرج**: 0
- **مثال**:
```
trace("دخلنا الدالة")
```

- **المخرج**: 0

## 13. المكتبة القياسية (Standard Library)

يتم تحميل المكتبة القياسية تلقائياً عند بدء التشغيل. لا تحتاج لاستيرادها — جميع الدوال متوفرة مباشرة.

### math — دوال رياضية

```
abs(x)        # القيمة المطلقة
sqrt(x)       # الجذر التربيعي
sin(x)        # جيب الزاوية
cos(x)        # جيب التمام
tan(x)        # ظل الزاوية
floor(x)      # تقريب لأسفل
ceil(x)       # تقريب لأعلى
round(x)      # تقريب عادي
max(a, b)     # القيمة الأكبر
min(a, b)     # القيمة الأصغر
clamp(x, lo, hi)  # حصر القيمة بين حدين
lerp(a, b, t) # الاستيفاء الخطي
sign(x)       # إشارة العدد (-1, 0, 1)
pi()          # قيمة π
```

- **مثال**:
```
print(sqrt(16))      # 4
print(clamp(5, 0, 3)) # 3
print(pi())          # 3.14159...
```

### string — دوال النصوص

```
split(s, sep)      # تقسيم النص إلى مصفوفة
join(list, sep)    # دمج مصفوفة نصوص
reverse(s)         # عكس النص
trim(s)            # إزالة المسافات
startsWith(s, p)   # هل يبدأ ببادئة؟
endsWith(s, p)     # هل ينتهي بلاحقة؟
count(s, sub)      # عدد مرات ظهور نص فرعي
repeat(s, n)       # تكرار النص
padLeft(s, len, ch)   # تعبئة من اليسار
padRight(s, len, ch)  # تعبئة من اليمين
```

- **مثال**:
```
print(trim("  hello  "))        # "hello"
print(repeat("Ha", 3))          # "HaHaHa"
```

### list — دوال المصفوفات

```
first(list)       # أول عنصر
last(list)        # آخر عنصر
take(list, n)     # أول n عناصر
skip(list, n)     # تخطي أول n عناصر
range(start, end) # إنشاء مصفوفة أرقام
flatten(list)     # تسوية المصفوفات المتداخلة
chunk(list, size) # تقسيم لمجموعات
```

- **مثال**:
```
let r = range(1, 5)           # [1, 2, 3, 4, 5]
let f = first(r)              # 1
let ch = chunk(r, 2)          # [[1, 2], [3, 4], [5]]
```

### datetime — دوال التاريخ والوقت

```
now()             # الوقت الحالي (Unix timestamp بالملي ثانية)
addDays(ts, n)    # إضافة أيام
addHours(ts, n)   # إضافة ساعات
addMinutes(ts, n) # إضافة دقائق
```

- **مثال**:
```
let t = now()
let tomorrow = addDays(t, 1)
```
