# دليل تثبيت لغة A+ والإعداد الكامل

> جميع الخطوات والأدوات المطلوبة لتشغيل لغة A+ على ويندوز، لينكس، وماك.

---

## 1. المتطلبات الأساسية

| الأداة | الغرض | رابط التحميل |
|--------|-------|-------------|
| **.NET SDK 10.0** | تشغيل مترجم A+ (إجباري) | https://dotnet.microsoft.com/download/dotnet/10.0 |
| **Node.js (npm)** | تبعيات إضافة VS Code (اختياري) | https://nodejs.org/ |
| **VS Code** | المحرر (اختياري — يمكن استخدام أي محرر نصوص) | https://code.visualstudio.com/ |

---

## 2. تثبيت .NET SDK

```
# تحقق من التثبيت:
dotnet --version

# إذا لم يكن مثبتاً، حمّله من الرابط أعلاه
# وأعد تشغيل الطرفية
```

> يجب أن يظهر الإصدار `10.0.x` أو أحدث.

---

## 3. بناء مشغّل A+ (A+ Runner)

المشغّل هو القلب — يترجم وينفذ أكواد A+.

```
cd vscode-a-plus/runner
dotnet build A_Plus_Console.csproj -c Release
```

أو للاختبار السريع:

```
dotnet run --project vscode-a-plus/runner/A_Plus_Console.csproj -- "A+_Examples/19_Components/component_demo.a"
```

---

## 4. تثبيت إضافة VS Code

### الطريقة الأولى: من Marketplace
- افتح VS Code
- اذهب إلى Extensions (`Ctrl+Shift+X`)
- ابحث عن `A+ Language`
- اضغط Install

### الطريقة الثانية: يدوياً من سطر الأوامر
```
cd vscode-a-plus
npm install
code --install-extension .
```

### الطريقة الثالثة: عبر سكريبت التثبيت المدمج
```
# Windows:
powershell -ExecutionPolicy Bypass .\vscode-a-plus\install.ps1

# Linux/Mac:
bash vscode-a-plus/install.sh
```

---

## 5. تشغيل أول برنامج A+

### من VS Code
1. افتح ملف `.a` أو `.r.a`
2. اضغط `Ctrl+Shift+Alt+R` أو `F5`
3. أو من Command Palette: `A+: Run File`

### من الطرفية
```
# تشغيل مباشر
dotnet run --framework net10.0 --project vscode-a-plus/runner -- "A+_Examples/19_Components/component_demo.a"

# أو بعد البناء:
dotnet vscode-a-plus/runner/bin/Release/net10.0/A_Plus_Console.dll "A+.a"
```

### تشغيل مع واجهة WPF (ويندوز فقط)
```
dotnet run --framework net10.0-windows --project vscode-a-plus/runner -- "app.a"
```

## 6. نشر التطبيقات (Package)

### للمنصات المختلفة

| الأمر | الناتج |
|-------|--------|
| `-os web` | تطبيق ويب (HTML + JS) |
| `-os exe` | ملف EXE لويندوز |
| `-os linux` | ملف ثنائي للينكس |
| `-os macos` | تطبيق لماك |
| `-os apk` | تطبيق أندرويد |
| `-os ios` | تطبيق آيفون (يتطلب macOS) |
| `-os all` | جميع المنصات |

### أمثلة

```
# تطبيق ويب
dotnet run --project vscode-a-plus/runner -- package app.a myapp -os web -o ./build

# تطبيق ويندوز
dotnet run --project vscode-a-plus/runner -- package app.a myapp -os exe -o ./build

# تطبيق أندرويد
dotnet run --project vscode-a-plus/runner -- package app.a myapp -os apk -o ./build
```

---

## 7. نشر لتطبيقات الجوال (MAUI)

### تثبيت MAUI
```
dotnet workload install maui
dotnet workload list       # تأكد من ظهور maui
```

### متطلبات إضافية

| المنصة | المتطلب |
|--------|---------|
| **Android** | Android SDK (`dotnet android` أو Android Studio) |
| **iOS** | macOS + Xcode (لا يمكن بناء iOS إلا على ماك) |

### حزم APK (أندرويد)
```
dotnet run --project vscode-a-plus/runner -- package app.a myapp -os apk -o ./build
```
> المرة الأولى قد تأخذ وقتاً لتثبيت Android SDK تلقائياً.

### حزم iOS
```
# يتطلب macOS + Xcode
dotnet run --project vscode-a-plus/runner -- package app.a myapp -os ios -o ./build
```

## 8. الأوضاع المختلفة

| الأمر | الوصف |
|-------|-------|
| `a+ file.a` | تشغيل ملف |
| `a+ dir/` | تشغيل مشروع (index.a + ملفات) |
| `a+ -i` | وضع تفاعلي (REPL) |
| `a+ -d file.a` | وضع التصحيح (DAP — يتكامل مع VS Code) |
| `a+ -ml` | وضع متعدد اللغات (عربي/إنجليزي) |
| `a+ -N MyApp` | إنشاء مشروع جديد |

## 12. استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| `dotnet` not found | ثبّت .NET SDK 10.0 من [dotnet.microsoft.com](https://dotnet.microsoft.com/download/dotnet/10.0) |
| `code` not found | أضف VS Code إلى PATH أو استخدم التثبيت اليدوي |
| Build error في MAUI | شغّل `dotnet workload install maui` |
| Android SDK missing | شغّل البرنامج مرة أخرى — سيحاول التثبيت تلقائياً |
| iOS build fails | يتطلب macOS مع Xcode |
| `File not found` | تأكد من المسار الصحيح لملف `.a` |
| Syntax error | تأكد من كتابة الكود بشكل صحيح |
